Windowed Word Count

window stateful aggregation

Count word frequencies in 10-second tumbling windows. Demonstrates flat_map, key_by exchange, and windowed aggregation.

word_count.rs 
#[rhei::pipeline]
fn main(graph: &DataflowGraph) {
    graph.source(KafkaSource::new(broker, group, &["text"])?)
        .flat_map(|msg| {
            msg.text.split_whitespace()
                .map(|w| w.to_lowercase())
                .collect::<Vec<_>>()
        })
        .key_by(|word| word.clone())
        .window(TumblingWindow::new(Duration::from_secs(10)))
        .aggregate(CountAggregator)
        .sink(PrintSink::new());
}

Order Enrichment (Temporal Join)

join stateful multi-source

Join order events with customer data. Unmatched events are automatically evicted after the timeout — no manual state cleanup.

order_enrichment.rs 
#[rhei::pipeline]
fn main(graph: &DataflowGraph) {
    let orders = graph.source(
        KafkaSource::new(broker, group, &["orders"])?
    );
    let customers = graph.source(
        KafkaSource::new(broker, group, &["customers"])?
    );

    orders
        .key_by(|o| o.customer_id.clone())
        .temporal_join(
            customers.key_by(|c| c.id.clone()),
            Duration::from_secs(30),
            |order, customer| EnrichedOrder {
                order_id: order.id,
                customer_name: customer.name.clone(),
                amount: order.amount,
            },
        )
        .sink(KafkaSink::new(broker, "enriched-orders")?);
}

Clickstream Sessions

session window gap-based

Group user click events into sessions based on 5-minute inactivity gaps. Filter to sessions with meaningful engagement before sinking.

click_sessions.rs 
#[rhei::pipeline]
fn main(graph: &DataflowGraph) {
    graph.source(KafkaSource::new(broker, group, &["clicks"])?)
        .key_by(|click| click.user_id.clone())
        .window(SessionWindow::new(
            Duration::from_secs(300),  // 5 min inactivity gap
        ))
        .aggregate(SessionAggregator)
        .filter_fn(|session| session.click_count > 3)
        .sink(KafkaSink::new(broker, "sessions")?);
}

Fraud Detection (Sequence Matching)

sequence pattern nfa

Detect "small transaction followed by large transaction within 60 seconds" — a common card testing pattern. Uses NFA-based pattern matching, equivalent to SQL MATCH_RECOGNIZE.

fraud_detection.rs 
#[rhei::pipeline]
fn main(graph: &DataflowGraph) {
    graph.source(KafkaSource::new(broker, group, &["transactions"])?)
        .key_by(|txn| txn.card_id.clone())
        .operator("fraud-detect", SequenceDetect::builder()
            .step("probe", |t: &Transaction| t.amount < 10.0)
            .step("exploit", |t: &Transaction| t.amount > 5000.0)
            .within(Duration::from_secs(60))
            .build()
        )
        .sink(KafkaSink::new(broker, "fraud-alerts")?);
}

Rolling Metrics (Sliding Window)

sliding overlap metrics

Compute 5-minute rolling average latency, emitting updated results every 30 seconds. Overlapping windows with configurable slide interval.

rolling_metrics.rs 
#[rhei::pipeline]
fn main(graph: &DataflowGraph) {
    graph.source(KafkaSource::new(broker, group, &["requests"])?)
        .key_by(|req| req.service_name.clone())
        .window(SlidingWindow::new(
            Duration::from_secs(300),  // 5 min window
            Duration::from_secs(30),   // 30s slide
        ))
        .aggregate(LatencyAggregator)
        .filter_fn(|m| m.p99_ms > 500.0)  // alert threshold
        .sink(KafkaSink::new(broker, "latency-alerts")?);
}

Custom Stateful Operator

#[rhei::op] KeyedState custom

The #[rhei::op] proc macro generates a StreamFunction from an async function. Full control over batch iteration and typed state — without the trait boilerplate.

running_total.rs 
use rhei::prelude::*;

#[rhei::op]
async fn running_total(
    input: RheiBuffer<Purchase>,
    ctx: &mut OperatorContext,
) -> anyhow::Result<BufferOutput<UserSpend>> {
    let mut builder = UserSpend::builder(input.len());

    for (phys_idx, _) in input.iter().enumerate_physical() {
        let view = Purchase::view(input.as_record_batch(), phys_idx);

        let mut state = KeyedState::<String, f64>::new(
            &mut ctx.state, "totals"
        );
        let prev = state.get(&view.user_id.to_string()).await?
            .unwrap_or(0.0);
        let new_total = prev + view.amount;
        state.put(&view.user_id.to_string(), &new_total)?;

        builder.append(UserSpend {
            user_id: view.user_id.to_string(),
            total: new_total,
        });
    }

    Ok(BufferOutput::Single(RheiBuffer::from_builder(builder)))
}

// Use it in a pipeline:
#[rhei::pipeline]
fn main(graph: &DataflowGraph) {
    graph.source(KafkaSource::new(broker, group, &["purchases"])?)
        .key_by(|p| p.user_id.clone())
        .operator("running-total", RunningTotal)
        .filter_fn(|spend| spend.total > 1000.0)
        .sink(KafkaSink::new(broker, "high-spenders")?);
}
